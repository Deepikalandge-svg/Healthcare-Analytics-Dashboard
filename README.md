Healthcare Analytics Dashboard

Project Overview

This project analyzes healthcare data and presents key insights through an interactive Tableau dashboard.

Objectives

- Analyze important healthcare metrics.
- Identify trends and patterns in the dataset.
- Present insights using interactive visualizations.

Tools Used

- Tableau
- Microsoft Excel
- Data Cleaning and Data Visualization

Key Features

- Interactive dashboard
- Filters and charts
- KPI summaries
- Data-driven insights

Files Included

- Tableau workbook
- Dataset (where sharing is permitted)
- Dashboard screenshots

Author

Deepika Landge 

How to View

Download the Tableau workbook and open it using Tableau Desktop or a compatible Tableau application.
